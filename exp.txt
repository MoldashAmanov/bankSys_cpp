protected - поля доступны в наследниках, но не снаружи
virtual - позволяет переопределять методы в наследниках
= 0 - делает метод число виртуальным, класс становится абстрактным
override - явно указывает, что метод переопределяет виртуальный метод базового класса
public Account - публичное наследование (DebitAccount ЯВЛЯЕТСЯ Account)
unique_ptr<> - умный указатель, автоматически удаляет объект при выходе из области видимости
Account* - сырой указатель для возврата (не владеет объектом, только ссылаемся)
move(acc) - передаем владение умным указателем
acc.get() - получаем сырой указатель из умного (для возврата)
acc-> вызываем метод через указатель
make_unique - современный способ создать умный указатель
try-catch - обработка исключений
exception - базовый класс для всех стандартных исключений
